# Art Direction Resolution

Resolve visual direction before production, but do not turn this into a mandatory client questionnaire.

## Output: Art Direction Brief

### Visual Intent
What should the audience perceive/feel?

### Visual Thesis
One concise design proposition that explains why the system should look this way. Avoid empty adjective stacking.

Example:
> Quiet Precision — express technology through controlled spacing, restrained material, and precise reflection rather than neon HUD clichés.

### Visual Priority Basis
Decide where visual resources should primarily go for this output, for example:
- product form / material,
- function / evidence,
- emotion / context.

This is a design question, not a mandatory second taxonomy.

### Hero Relation
Define the dominant relationship in the frame, for example:
- Product-dominant
- Product + Context
- Product + Evidence
- Product + Copy
- Product + Offer

Do not use a fixed product-area percentage as a universal rule.

### Visual Impact Levers
Use 2–4 intentionally when they materially improve the visual:
- **Scale**
- **Crop**
- **Angle**
- **Space**
- **Light**
- **Motion**

Impact should come from controlled visual relationships, not automatically from more saturation, glow, particles, HUD, or decorative speed lines.

## Hero / KV craft framework
For a hero image, poster, launch KV, or other first-impression visual, resolve enough craft structure to make the direction executable:
- **Primary focal event:** what the eye should notice first and why.
- **Product relation:** product-dominant, product + context, product + copy, product + evidence, or another deliberate relationship.
- **Composition mechanism:** scale contrast, crop, asymmetry, depth, framing, diagonal/axis tension, repetition, or another purposeful structure.
- **Typography role:** headline as quiet support, counterweight, spatial anchor, or dominant graphic form; avoid default text-block placement.
- **Light/material mechanism:** how light, shadow, reflection, texture, or atmosphere strengthens the product rather than merely decorating the background.
- **Scene semantics:** which objects/actions make the use context legible, and which props should be excluded.
- **Brand-specific device:** a repeatable visual behavior, not merely a logo placed on a generic layout.

At least one of these mechanisms should create a distinctive visual proposition beyond generic category styling.

### Template-resistance check
Before production, ask whether the same layout would remain essentially unchanged if the product and logo were swapped for another brand in the category. If yes, strengthen product-specific or brand-specific visual logic before rendering.

### Reference Translation
For each reference:
- role,
- what to take,
- what to preserve,
- what not to copy.

When visual benchmarking was run, translate each selected reference into one or more concrete mechanisms used by the current direction. Do not use references only as mood labels.

Reference roles:
- PRODUCT_REFERENCE
- INSPIRATION_REFERENCE
- EXECUTION_REFERENCE
- SCENE_REFERENCE
- COMPOSITION_REFERENCE
- MOTION_REFERENCE
- NEGATIVE_REFERENCE
- PROOF_REFERENCE
- BRAND_REFERENCE

### Negative Direction
Define both:
- **Anti-board:** visual directions not wanted.
- **Anti-slop:** generic AI filler/clichés to avoid.

Examples:
random HUD, meaningless micro-text, generic luxury black-gold, purposeless neon glow, irrelevant glass cards, decorative data with no meaning.

## Rule
Art Direction is a resolution process. Persist only the approved outputs into the Campaign Visual System, not the full hidden reasoning.
