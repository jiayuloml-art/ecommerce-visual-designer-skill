# Static Medium Grammar

Core question: **How is attention allocated in one simultaneous visual field?**

Resolve:
- Focal Point
- Visual Hierarchy
- Composition
- Product Scale: Dominant / Balanced / Supporting
- Product–Text Relationship
- Information Density: Low / Medium / High
- Negative Space

Common risks:
- multiple competing primary focal points,
- detail-page information forced into one image,
- style adjectives without hierarchy/composition decisions.
