# Long-form Medium Grammar

Core question: **How does information architecture sustain scrolling and decision-making?**

Resolve:
- Above-the-fold role
- Module architecture
- Section hierarchy
- Scroll rhythm
- Section transitions
- Progressive detail
- Decision-support zone

Long-form is not a stack of unrelated posters. It should progressively move from identity/value to explanation/proof/decision support/action as appropriate.

## E-commerce detail-page production
A directly requested detail page needs an actually rendered first screen plus a complete ordered module set, not only a long-image outline. The first screen establishes identity and core value. Downstream modules explain confirmed benefits, use, proof and purchase questions, each with a distinct role when applicable.

Derive module count from the complete confirmed selling-point inventory. For each module track its ID, order, Communication Job, covered selling-point IDs, image or inspectable crop, dimensions, crop bounds and actual completion state. Confirm sequence, full coverage and export readiness. A stitched overview is optional and never replaces missing modules.
