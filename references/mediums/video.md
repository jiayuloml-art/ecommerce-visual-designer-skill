# Video / Temporal Medium Grammar

Core question: **How is attention and information allocated over time?**

Resolve:
- Hook
- Duration
- Narrative arc
- Shot role
- Pacing
- Motion
- Audio
- Subtitle / on-screen text
- CTA timing

Common arcs:
- Hook → Product → Value → CTA
- Problem → Product → Demo → Result → CTA
- Product → Action → Result → Proof
- Scenario → Product integration → Experience → Brand

Do not duplicate the same sentence simultaneously in visual, voiceover, and subtitle unless emphasis is intentional.
