# Sequence Medium Grammar

Core question: **What does each page/frame do, and why should the user continue?**

Resolve:
- Entry / Cover function
- Page Role
- Sequence logic
- Reveal logic
- Transition
- Rhythm
- Repetition & Variation
- Ending logic

Possible sequence logics:
- Problem → Solution → Proof → Action
- Overview → Feature → Detail → Scenario → Proof
- Scenario → Experience → Benefit → Product
- Existing solution → Difference → Product → Value

Do not fix page count by template. Let communication job determine necessary modules.
